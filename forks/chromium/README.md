# بناء Fork مخصص مباشر من كود Chromium الأصلي

## كيف تُبنى المتصفحات المشهورة المبنية على كروميوم؟
مشاريع مثل **Brave**, **Ungoogled-Chromium**, **Thorium**, **Cromite** لا تقوم برفع 100 جيجابايت من كود كروميوم إلى GitHub!
بل تستخدم استراتيجية احترافية تُسمى **"Patch-based Forking"**:
1. جلب كود كروميوم الرسمي عند إصدار مستقر معين (مثلاً Tag `128.0.6613.119`) عبر أداة `depot_tools`.
2. تطبيق الباتشات البرمجية (`.patch`) المكتوبة بلغة C++ لتعديل الواجهة، حذف التتبع، أو إضافة ميزات حصرية.
3. تفعيل خيارات البناء `args.gn` لتحسين السرعة والترميزات (Codecs).
4. ترجمة المتصفح باستخدام نظام البناء السريع `Ninja` و `GN`.

---

## المتطلبات التقنية للجهاز (Hardware Requirements):
- **المعالج:** 8 أنوية (Cores) على الأقل (يفضل 16 أو أكثر).
- **الذاكرة العشوائية (RAM):** 32 جيجابايت كحد أدنى (الـ Linking يستهلك 16-24GB وحدها)، أو 16GB مع 32GB Swap.
- **مساحة القرص:** 100 إلى 150 جيجابايت SSD فائقة السرعة.
- **نظام التشغيل:** Ubuntu 22.04 / 24.04 LTS أو Debian 12 أو Windows 11 مع MSVC 2022.

---

## خطوات التشغيل عبر السكربتات التلقائية:

### الخطوة 1: تثبيت حزمة depot_tools والمكتبات المطلوبة
```bash
chmod +x scripts/*.sh
./scripts/01_install_prerequisites.sh
```

### الخطوة 2: جلب كود المصدر لكروميوم
```bash
./scripts/02_fetch_chromium.sh 128.0.6613.119
```

### الخطوة 3: تطبيق التعديلات والباتشات المخصصة
```bash
./scripts/03_apply_patches.sh
```

### الخطوة 4: بدء الترجمة والبناء
```bash
./scripts/04_build.sh
```

الناتج سيكون ملف التشغيل النهائي:
`$HOME/chromium_build/src/out/Default/chrome`
