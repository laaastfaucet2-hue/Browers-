## 🌟 أحدث الميزات الجوهرية المنجزة (All Next-Gen Systems Active)

### 1. 🛠️ بيئة المطورين وفاحص الشبكة الحي (Built-in DevTools & Live JS Console)
- فاحص شبكة متزامن مع طلبات التصفح يعرض عناوين الموارد (URL)، رموز الاستجابة (Status 200)، نوع البيانات (MIME Type)، الحجم، وزمن الوصول (Latency ms).
- كونسول تفاعلي (Interactive JS Console) لتقييم وتنفيذ أكواد JavaScript الحية مباشرة على الـ DOM.
- شجرة فحص عناصر الصفحة (DOM Element Tree Inspector) مع إمكانية الفتح بضغطة زر أو باختصار `F12`.

### 2. 🔐 الخزنة المشفرة وإدارة كلمات المرور (AES-256 Encrypted Password Vault)
- تشفير محلي عالي الأمان لحسابات المستخدمين وكلمات المرور على الرابط `about:passwords`.
- مولد كلمات مرور معقدة (Crypto-grade Password Generator) مع مقياس قوة كلمة المرور (Strength Score 0-100%).
- درع فحص التسريبات الاستباقي (Data Breach Detection) للتنبيه في حال استخدام كلمات مرور مسربة أو ضعيفة.

### 3. 📑 تجميع الألسنة الذكي في مجلدات ملونة (Smart Tab Groups & Collapsible Stacks)
- تنظيم علامات التبويب داخل مجلدات ملونة قابلة للطي والفرد (مثل `[● مهام التطوير]` و `[● الأبحاث]`).
- تقليل فوضى الألسنة الكثيرة وزيادة التركيز وسرعة الوصول.

### 4. 📝 لوحة الملاحظات وقصاصات الويب الذكية (Web Scratchpad & Arc Easel)
- شريط جانبي لتدوين الملاحظات والخواطر بصيغة Markdown وحفظها تلقائياً مع الوقت والتاريخ.
- ميزة **قص الصفحة (Clip Page)** لنسخ نصوص وروابط المواقع كمرجع سريع للبحث والبرمجة.

### 5. 🎛️ لوحة التحكم في عتاد الجهاز ومشغل الوسائط العائم (Hardware Limiter & Floating PiP)
- **محدد استهلاك المعالج (CPU Limiter):** شريط تمرير لتحديد سقف استخدام المتصفح للمعالج (10% - 100%) لضمان عدم إبطاء الجهاز أثناء الألعاب والبرمجة.
- **محدد استهلاك الذاكرة (RAM Limiter):** تحديد الحد الأقصى للرام (512MB - 8192MB) مع نمط الإغلاق الصارم (Hard Limit).
- **مشغل الفيديو العائم (Picture-in-Picture):** نافذة فيديو مستقلة عائمة فوق كل التطبيقات مع تحكم كامل بالسرعة (0.5x, 1x, 1.25x, 1.5x, 2x) وكتم الصوت.

### 6. 🧩 دعم كامل وحقيقي لمتجر إضافات فايرفوكس (addons.mozilla.org - AMO)
- متجر مدمج لإضافات فايرفوكس الرسمية مع بحث وتصفية حية وتثبيت مباشر بنقرة زر (`+ أضف إلى فايرفوكس`).
- تشغيل وحقن فعلي لأكواد الإضافات (مثل **Dark Reader 🌙** الذي يحول كافة صفحات الويب للوضع الداكن فوراً، و **uBlock Origin 🛑** لحجب الإعلانات، و **Firefox Translate 🌐** للترجمة).

### 7. 🛡️ عزل الحاويات المتعددة (Multi-Account Containers & Auto-Router)
- عزل ملفات تعريف الارتباط والجلسات لكل هوية: **شخصي (Personal)**، **العمل (Work)**، **البنوك (Banking)**، **التسوق (Shopping)**.
- توجيه تلقائي ذكي للروابط الحساسة إلى حاويتها المخصصة تلقائياً.

### 8. 🤖 محرك الذكاء الاصطناعي المدمج (Native C++ AI Copilot Engine)
- شريط جانبي تفاعلي (`🤖 Atlas AI`) مع تلخيص فوري للصفحات وشرح الأكواد البرمجية وفحص الخصوصية.

### 9. 📥 مدير التنزيلات فائق السرعة وفحص الأمان (Turbo Download Manager)
- تنزيل متعدد المسارات (Multi-threaded Chunked Downloads) بسرعة فائقة مع فحص أمني ضد البرمجيات الخبيثة.

### 10. ⚡ درع مراقبة الأداء وتوفير الذاكرة (Performance Shield)
- قياس استهلاك الرام والمعالج لكل لسان وتوفير أكثر من **+420 MB** عبر تجميد التبويبات الخاملة.

## 💻 نظام الأجهزة الافتراضية المعزولة (200 Virtual Device Profiles - Anti-Detect)

تم تزويد المتصفح بمحرك متقدم لإدارة حتى **200 بيئة تصفح وجهاز افتراضي متزامن**:
1. **عزل كلي للتخزين والجلسات (Storage & Cookies Sandbox):**
   - لكل جهاز افتراضي مسار مستقل تماماً (`profiles/virtual_device_X/`) لملفات تعريف الارتباط، التخزين المحلي (LocalStorage)، وقواعد بيانات IndexedDB.
2. **تزييف عميق للبصمة العتادية (Deep Hardware Anti-Detect):**
   - **WebGL Renderer & Vendor Spoofing:** تزييف كرت الشاشة الحقيقي (NVIDIA GeForce RTX 4090, Apple M3 Max, AMD Radeon RX 7900, Intel UHD Graphics) وتجاوز استعلامات `WEBGL_debug_renderer_info`.
   - **Canvas Noise Farbling:** حقن تشويش دقيق ومحسوب في مصفوفة بكسلات الـ HTML5 Canvas لتوليد قيمة Hash مشوشة وفريدة لكل جهاز افتراضي مع الحفاظ على سلامة الرسوم.
   - **AudioContext Micro-Frequency Shift:** تزييف منحنى ترددات الصوت بمقدار ميكروي فريد يمنع التعرف على كرت الصوت الفعلي.
   - **Hardware Concurrency & Device Memory:** تزييف عدد الأنوية (8, 12, 16, 24 Cores) وحجم الرام (16GB, 32GB, 64GB) وأبعاد الشاشة ونسبة البكسل (DPR).
   - **ملاحظة:** تم استثناء عنوان الـ IP والبروكسي حالياً استجابةً لتوجيهاتكم الصريحة، مع التركيز الصارم على حماية البصمة العتادية والجهازية.
3. **شاشة العرض المتعددة المتزامنة (Multi-Device Matrix Grid):**
   - إمكانية تشغيل متصفحات متعددة جنباً إلى جنب في نفس الواجهة كأجهزة وأنظمة تشغيل مستقلة كلياً.

## 🚀 البناء والتشغيل والاختبارات الآلية

```bash
make clean && make all
```

```bash

./bin/atlas_browser_server 8080
```
