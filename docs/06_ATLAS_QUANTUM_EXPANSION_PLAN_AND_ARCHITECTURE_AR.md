## 1. الرؤية والهدف الاستراتيجي

الهدف من مشروع **AtlasBrowser** هو بناء متصفح ويب عملاق، سيادي، وعالي الأداء، لا يكتفي بكونه مجرد غلاف (Wrapper) بسيط، بل يمتلك طبقة نواة مكتوبة بالكامل بلغة **C++20**، ترتبط بنواة **Gecko / SpiderMonkey (Mozilla Firefox)** لتمكين:
1. التوافق بنسبة 100% مع كافة إضافات فايرفوكس الرسمية عبر منصة AMO دون قيود توقيع رقمي.
2. الحفاظ على واجهات برمجة التطبيقات القديمة والحديثة لإضافات حجب الإعلانات (Manifest V2 و WebRequest API الكاملة).
3. الفصل التام للجلسات وبيانات التصفح عبر نظام الحاويات المتعددة (Multi-Account Containers).
4. تزويد المتصفح بميزات العصر الحديث المتقدمة: ألسنة جانبية، مساحات عمل، تقسيم شاشة، ذكاء اصطناعي، ومدير تنزيلات متطور.

## 2. الركائز الست الكبرى لخطة التطوير العملاقة

### 🤖 الركيزة الأولى: محرك الذكاء الاصطناعي المدمج
- **الملفات:** `include/browser_core/AiAssistantEngine.hpp` و `src/browser_core/AiAssistantEngine.cpp`.
- **القدرات المدمجة:**
  - **تلخيص الصفحات الفوري:** استخراج النقاط المحورية والكلمات المفتاحية من محتوى التبويب النشط.
  - **محلل وشاحن الأكواد البرمجية (Code Analyzer):** فحص الأكواد وشرحها وتوضيح معايير الأمان وذاكرة C++.
  - **الترجمة الفورية:** ترجمة المقالات والفقرات للغة العربية.
  - **لوحة تفاعلية (Side Drawer):** شريط جانبي منزلق متصل بـ `/api/ai/ask` للتفاعل المباشر أثناء التصفح.

### 📥 الركيزة الثانية: مدير التنزيلات فائق السرعة وفحص الأمان
- **الملفات:** `include/browser_core/DownloadManager.hpp` و `src/browser_core/DownloadManager.cpp`.
- **الميزات الهندسية:**
  - دعم التنزيل متعدد المسارات (Multi-threaded chunked downloads).
  - إمكانية الإيقاف المؤقت (Pause)، الاستئناف (Resume)، والإلغاء (Cancel).
  - درع الفحص الاستباقي للكشف عن البرمجيات الخبيثة والملفات ذات الامتدادات الخطرة (`.scr`, `.vbs`, `.bat`).
  - صفحة داخلية مخصصة `about:downloads` لعرض السرعة الحالية والحالة الأمنية.

### 📖 الركيزة الثالثة: وضع القراءة والتركيز الفائق
- **الملفات:** `include/browser_core/ReaderModeEngine.hpp` و `src/browser_core/ReaderModeEngine.cpp`.
- **الميزات الهندسية:**
  - تحويل أي صفحة ويب مزدحمة بالإعلانات إلى مقال نقي بخطوط طباعية مريحة للعينين.
  - دعم أنماط ألوان القراءة: الداكن (Dark) وسيبيا (Sepia) والورقي (Light).
  - متاح عبر الرابط الداخلي `about:reader` أو زر الأيقونة السريعة `📖`.

### ⚡ الركيزة الرابعة: درع مراقبة الأداء وتوفير الذاكرة
- **الملفات:** `include/browser_core/PerformanceMonitor.hpp` و `src/browser_core/PerformanceMonitor.cpp`.
- **الميزات الهندسية:**
  - قياس استهلاك الذاكرة (RAM) والمعالج (CPU) لكل لسان تصفح بدقة.
  - ميزة إراحة الألسنة الخاملة (Tab Discarding / Sleeping Tabs) عند عدم استخدامها لتوفير الرام.
  - عداد الذاكرة الموفرة الناتجة عن حجب الإعلانات وتجميد التبويبات (+420 MB).
  - صفحة داخلية متكاملة `about:performance` بمؤشرات بيانية دقيقة.

### 🎨 الركيزة الخامسة: محرك السمات الديناميكي المتعدد
- **السمات المدعومة:**
  1. **الداكن الكلاسيكي (Slate Dark):** المظهر الافتراضي الاحترافي.
  2. **الأسود النقي (OLED True Black):** للشاشات الحديثة لتوفير طاقة البطارية ومنع إجهاد العين.
  3. **سايبربانك نيون (Cyberpunk Neon):** تدرجات بنفسجية وضوء سماوي مشع.
  4. **نورد الثلجي (Nord Minimal):** باليت نورد المستوحاة من ثلوج القطب الشمالي.
- التبديل السريع بضغطة زر `🎨` من الشريط العلوي أو عبر لوحة الأوامر السريعة.

### 🛡️ الركيزة السادسة: عزل الحاويات ودعم إضافات فايرفوكس
- **الملفات:** `ContainerManager`, `AutoContainerRouter`, `WorkspaceManager`.
- **الميزات:**
  - تكامل متجر إضافات فايرفوكس الرسمي (AMO) مع إمكانية تثبيت uBlock Origin و Dark Reader بنقرة واحدة.
  - عزل ملفات تعريف الارتباط لكل هوية (Personal, Work, Banking, Shopping).
  - التوجيه التلقائي للمواقع الحساسة إلى حاويتها المخصصة تلقائياً فور كتابة الرابط.
  - دعم مساحات العمل المستقلة (Workspaces) وتقسيم الشاشة المزدوج (Split View).

## 3. معمارية النظام وهيكل الكود البرمجي

```text
Browers-/
├── bin/                                # الملفات التنفيذية الناتجة عن البناء
│   ├── atlas_browser_core             # محرك C++ الأساسي مع CLI و26 اختبار آلي
│   └── atlas_browser_server           # خادم الواجهة التفاعلية الحية
├── include/browser_core/              # واجهات الأنظمة البرمجية (C++ Headers)
│   ├── AdBlocker.hpp                  # حجب الإعلانات والتعقب
│   ├── AiAssistantEngine.hpp          # محرك الذكاء الاصطناعي والتخصيص
│   ├── AutoContainerRouter.hpp        # توجيه الروابط للحاويات المناسبة
│   ├── BookmarkHistoryStore.hpp       # إدارة المفضلات والسجل
│   ├── BrowserConfig.hpp              # إعدادات المحرك والنواة
│   ├── BrowserEngine.hpp              # الواجهة الموحدة للمتصفح (Master Facade)
│   ├── ContainerManager.hpp           # إدارة حاويات فايرفوكس
│   ├── DownloadManager.hpp            # مدير التنزيلات فائق السرعة
│   ├── JsBridge.hpp                   # جسر ربط C++ بـ JavaScript DOM
│   ├── NetworkInterceptor.hpp         # ترقية HTTPS وتنظيف الروابط
│   ├── PerformanceMonitor.hpp         # مراقبة الرام وتوفير الطاقة
│   ├── PrivacyShield.hpp              # درع مكافحة البصمة الرقمية
│   ├── ReaderModeEngine.hpp           # محرك وضع القراءة والتركيز
│   ├── SchemeHandler.hpp              # مسارات بروتوكولات about: و mybrowser://
│   ├── TabManager.hpp                 # إدارة الألسنة وتقسيم الشاشة
│   └── WorkspaceManager.hpp           # إدارة مساحات العمل (Arc/Zen)
├── src/
│   ├── browser_core/                  # التنفيذ البرمجي المكتبي للنواة (C++20)
│   └── browser_server/server.cpp      # خادم الويب والواجهة التفاعلية الحية
├── docs/                              # التوثيق والكتيبات الفنية
├── firefox_fork/                      # سكربتات تفرع وبناء فايرفوكس (Gecko)
└── Makefile                           # بناء المشروع المتكامل
```

## 4. طريقة البناء والاختبار الآلي المتكامل

### 1. تنظيف وبناء المشروع:
```bash
make clean && make all
```

### 2. تشغيل حزمة الفحص الشاملة (26 اختبار):
```bash
make test
```
تختبر الحزمة تلقائياً:
- ترقية HTTPS التلقائية.
- تنظيف معلمات التتبع (UTM / Facebook Click IDs).
- محرك حظر النطاقات المشبوهة.
- إنشاء الألسنة والملاحة العكسية وإراحة الذاكرة.
- مسارات البروتوكول الداخلي `mybrowser://` و `about:`.
- جسر ربط كود C++ بـ JavaScript DOM.
- دروع حماية البصمة الرقمية وWebRTC.
- تبديل وتعيين مساحات العمل (Workspaces).
- عزل الحاويات المتعددة لفايرفوكس ومطابقة الروابط.
- تلخيص المحتوى ومحادثة الذكاء الاصطناعي C++.
- بدء التنزيلات وتجاوب الفحص الأمني للبرمجيات الخبيثة.
- حسابات توفير الذاكرة وحالة الألسنة.
- تنسيق وضع القراءة بدون تشويش.

### 3. تشغيل الخادم التفاعلي:
```bash
./bin/atlas_browser_server 8080
```
الواجهة متاحة فوراً للمعاينة والتجربة المباشرة في المتصفح!

## 5. خارطة الطريق المستقبلية للإنتاج والتوزيع

1. **الربط مع حزم GeckoView / libxul الرسمية:** تجميع إصدار مستقل يعمل على منصات Linux و Windows و macOS.
2. **المزامنة المشفرة طرفاً لطرف (E2E Encrypted Sync):** مزامنة المفضلات، الألسنة المفتوحة، والمحفوظات عبر خادم ذاتي الاستضافة (Self-hosted Rust Sync Server).
3. **تطبيق وضع حماية الذكاء الاصطناعي محلياً (Local On-Device LLM):** ربط المحرك بنموذج llama.cpp مدمج يعمل بالكامل بدون اتصال بالإنترنت.
