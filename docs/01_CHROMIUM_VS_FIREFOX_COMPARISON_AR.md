# مقارنة شاملة وعميقة: كود Chromium مقابل كود Firefox لمطور C++

عندما تقرر بناء متصفحك الخاص وإضافة ميزاتك الخاصة بلغة **C++**، فإن أول قرار مصيري هو اختيار النواة الأساسية: **Chromium أم Firefox؟**
فيما يلي تشريح تقني دقيق للمحركين من واقع هندسة البرمجيات:

---

## 1. لغة البرمجة والمعمارية الداخلية (Codebase & Architecture)

| وجه المقارنة | Chromium (كروميوم) | Firefox (فايرفوكس / Gecko) |
| :--- | :--- | :--- |
| **محرك التصيير (Rendering Engine)** | **Blink** (تفرع من WebKit) | **Gecko** |
| **محرك الجافاسكريبت** | **V8** (مكتوب بـ C++) | **SpiderMonkey** (مكتوب بـ C++ و Rust) |
| **لغة كود النواة** | **C++ بنسبة تتجاوز 90%** (C++20 حديث) | **خليط من C++، Rust، و JavaScript** |
| **لغة برمجة واجهة المتصفح (UI)** | **C++ Views Framework** أو **Aura** أو **WebUI** | **HTML / CSS / JS** (نظام Fluent ومكونات الويب) |
| **معمارية العمليات (Multi-Process)** | معمارية رائدة: Browser Process, Renderer Processes, GPU Process, Network Service, Audio Service | معمارية Electrolysis (e10s) ثم Fission (Site Isolation) |
| **أدوات التضمين (Embedding APIs)** | **CEF (Chromium Embedded Framework)** و **Qt WebEngine** | **GeckoView** (ممتاز للأندرويد، لكن محدود على سطح المكتب) |

### الخلاصة للمطور المهتم بلغة C++:
- إذا كنت ترغب في أن تكون **كل أجزاء متصفحك بلغة C++** (من الواجهة إلى إدارة الشبكة والذاكرة)، فإن **Chromium** أو إطارات العمل المبنية عليه (مثل CEF أو Qt WebEngine) هو الخيار الطبيعي والأقوى، لأن نواة كروميوم مكتوبة بالكامل بـ C++.
- في فايرفوكس، أجزاء كبيرة من واجهة المستخدم وإعدادات المتصفح مكتوبة بـ JavaScript و XHTML/CSS، بينما النواة التحتية تستخدم C++ و Rust.

## 2. التوافق وسرعة التصفح (Web Standards & Performance)

### Chromium:
- **الحصة السوقية:** يسيطر محرك Blink على أكثر من 70% من حركة الويب في العالم (Chrome, Edge, Brave, Opera, Vivaldi).
- **التوافق:** جميع مواقع الويب العالمية (تطبيقات Google، Microsoft 365، Figma، منصات الألعاب) تُختبر وتُحسّن أولاً على كروميوم.
- **محرك V8:** أسرع محرك جافاسكريبت على الإطلاق في معالجة العمليات الرياضية والتطبيقات الثقيلة.

### Firefox:
- **الخصوصية والحرية:** فايرفوكس هو البديل المستقل الوحيد المتبقي لهيمنة كروميوم.
- **إضافات المتصفح:** يتمسك فايرفوكس بدعم واجهات **Manifest V2** بالكامل بجانب V3، مما يتيح لموانع الإعلانات (مثل uBlock Origin) العمل بأقصى كفاءة شبكية ممكنة.

## 3. متطلبات البناء والصيانة (Maintenance & Hardware)

| المتطلب | كود Chromium الأصلي | كود Firefox الأصلي | CEF / Qt WebEngine |
| :--- | :--- | :--- | :--- |
| **حجم كود المصدر** | ~50 - 100 GB | ~40 - 60 GB | ~1 - 2 GB (Prebuilt) |
| **الذاكرة العشوائية المطلوبة** | 32GB إلى 64GB RAM | 16GB إلى 32GB RAM | 4GB إلى 8GB RAM |
| **وقت البناء الأول** | 4 إلى 8 ساعات | 2 إلى 4 ساعات | 2 إلى 5 دقائق |
| **نظام البناء** | `GN` + `Ninja` + `depot_tools` | `Mach` + `Cargo/Rust` | `CMake` القياسي |
| **مواكبة التحديثات الأمنية** | تحديث كل أسبوعين إلى 4 أسابيع | تحديث كل 4 أسابيع | سحب أحدث إصدار وتحديث الروابط |

## 4. الحكم والتوصية النهائية:

1. **إذا كان هدفك متصفحاً شخصياً أو تجارياً مخصصاً بـ C++ بسرعة:**
   - **الخيار رقم 1:** استخدم **Chromium Embedded Framework (CEF)** أو **Qt WebEngine**.
   - ستحصل على نواة كروميوم كاملة، وتكتب متصفحك وميزاتك بالكامل بلغة C++، وتوفر على نفسك مئات الساعات في بناء وصيانة الكود الخام.

2. **إذا كان هدفك متصفحاً يحذف خدمات جوجل بالكامل ويعدل النواة مباشرة:**
   - اختر **Chromium Patch-Fork** (على غرار Ungoogled-Chromium أو Brave).
   - وفر جهازاً عالي المواصفات (32GB RAM و SSD سريع).

3. **إذا كان هدفك الخصوصية التامة ومقاومة احتكار كروميوم:**
   - اختر **Firefox Patch-Fork** (على غرار LibreWolf أو Zen Browser).
   - ستحتاج للتعامل مع مزيج من C++ و Rust و JavaScript.
