# خارطة الطريق الهندسية لتطوير متصفحك العملاق (Atlas Firefox Fork)

> **"المليون خطوة تبدأ بخطة محكمة، وتنفيذ مدروس خطوة بخطوة"**

بعد أن قمنا بتحويل معمارية المتصفح إلى نواة **Firefox (Gecko Engine)** وتفعيل دعم الإضافات الرسمية والحاويات المتعددة (Multi-Account Containers)، فيما يلي الخطة العملية التفصيلية للخطوات القادمة:

---

## 📌 المسار الزمني للتطوير (The 5 Milestones)

```text
[المرحلة 1] البناء الآلي الأولي (عبر GitHub Actions أو محلياً)
      │
      ▼
[المرحلة 2] برمجة ميزات C++ الحصرية في النواة (Gecko Core Subsystems)
      │
      ▼
[المرحلة 3] تطوير واجهة المتصفح المخصصة (Vertical Tabs & Custom UI)
      │
      ▼
[المرحلة 4] ربط متجر موزيلا الرسمي والإضافات المثبتة مسبقاً
      │
      ▼
[المرحلة 5] إنتاج ملفات التثبيت (.exe و .deb و .dmg) ونظام التحديثات
```

---

## 🚀 المرحلة 1: بناء أول نسخة تنفيذية (بدون إرهاق جهازك!)

بناء كود فايرفوكس الأصلي يحتاج إلى وقت وموارد معالجة كبيرة. لتسهيل الأمر عليك فوراً:
1. **البناء السحابي عبر GitHub Actions (الحل السحري):**
   - قمنا بإنشاء ملف العمل السحابي: `.github/workflows/build-firefox-fork.yml`.
   - بمجرد الدخول إلى صفحة المستودع على GitHub ثم تبويب **Actions**، اضغط على **"Run workflow"**.
   - خوادم GitHub ستقوم بتنزيل كود فايرفوكس، تطبيق باتشات `AtlasBrowser`، تفعيل الحاويات، وترجمة المتصفح بالكامل، ثم تخرج لك ملف البرنامج النهائي للتحميل في صفحة الـ Artifacts!

2. **أو البناء المحلي على جهازك:**
   ```bash
   cd firefox_fork
   ./scripts/01_setup_gecko_environment.sh
   ./scripts/02_fetch_firefox_source.sh
   ./scripts/03_apply_atlas_patches.sh
   ./scripts/04_build_atlas_browser.sh
   ./scripts/06_run_atlas_browser.sh
   ```

## 💻 المرحلة 2: برمجة ميزات C++ الحصرية في النواة

فايرفوكس مقسم إلى طبقات C++ واضحة، وإليك أين نضع ميزاتك القادمة:

### 1. التوجيه التلقائي للحاويات (Auto-Container Routing في C++):
- **المكان:** `caps/OriginAttributes.cpp` و `netwerk/protocol/http/nsHttpChannel.cpp`.
- **الفكرة:** جعل المتصفح ذكياً؛ إذا كتب المستخدم رابطاً لـ `github.com`، يقوم المتصفح تلقائياً بفتحه داخل **حاوية العمل (Work Container)** بدون تدخل من المستخدم، وإذا فتح موقع شراء يُوجهه لحاوية **التسوق (Shopping)**.

### 2. مانع إعلانات النواة فائق السرعة (Native Necko Adblocker):
- بدلاً من انتظار تشغيل الجافاسكريبت، نقوم بفحص وتصفية الطلبات الشبكية في دالة `nsHttpChannel::Connect()` في C++ مباشرة قبل بدء اتصال TCP.

### 3. درع البصمة الرقمية (Anti-Fingerprinting):
- تعديل دوال `HTMLCanvasElement.cpp` لتوليد تشويش ميكروي غير مرئي يمنع المواقع من تتبع جهازك.

## 🎨 المرحلة 3: تصميم الواجهة وتجربة المستخدم (UI Customization)

واجهة فايرفوكس الحديثة مبنية بنظام **Proton UI** وتستخدم لغات **HTML / CSS / JavaScript / Fluent**:
1. **الألسنة الجانبية المدمجة (Native Vertical Tabs):**
   - إضافة ميزة الألسنة الرأسية الجانبية المدمجة في الشريط الجانبي (مثل متصفح Arc و Zen Browser).
2. **صفحة البداية الحصرية (`about:home` و `about:newtab`):**
   - استبدال صفحة فايرفوكس الافتراضية بصفحة مخصصة باسم متصفحك وشعارك مع أدوات الإنتاجية.
3. **ملفات التخصيص البصري المباشر:**
   - استخدام `userChrome.css` لتعديل انحناءات النوافذ، الألوان، وشريط الأدوات ليصبح تحفة فنية مميزة.

## 📦 المرحلة 4 & 5: إنتاج ملفات التثبيت وإطلاق المتصفح

1. **لـ Windows:**
   - توليد مثبت رسمي: `AtlasBrowser-Setup.exe` عبر أداة NSIS الموجودة في `branding/branding.nsi`.
2. **لـ Linux:**
   - توليد حزم `.deb` (لـ Ubuntu و Debian) وحزم `.AppImage` القابلة للتشغيل على أي توزيعة بنقرة واحدة.
3. **لـ macOS:**
   - توليد ملف `AtlasBrowser.dmg` مع توقيع التطبيق.
